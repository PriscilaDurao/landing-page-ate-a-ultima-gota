# 🎬 Landing Page — Até a Última Gota

Uma landing page desenvolvida para promover o filme **Até a Última Gota**, utilizando uma interface moderna, responsiva e visualmente impactante.

O projeto foi desenvolvido durante a formação **Profissão: Engenheiro Front-end da EBAC**, com o objetivo de aplicar conceitos fundamentais do desenvolvimento web, criando uma experiência imersiva para a divulgação de uma produção cinematográfica.

---

## 🎯 Objetivo do Projeto

Desenvolver uma landing page inspirada no filme **Até a Última Gota**, aplicando conceitos de design, responsividade e interatividade para apresentar informações sobre a obra de forma atrativa e organizada.

---

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub
* Vercel

---

## ✨ Funcionalidades

* 🎬 Apresentação do filme
* 📱 Layout responsivo
* 🎨 Interface inspirada em plataformas de streaming
* ⚡ Elementos interativos desenvolvidos com JavaScript
* 🖥️ Compatibilidade com diferentes dispositivos
